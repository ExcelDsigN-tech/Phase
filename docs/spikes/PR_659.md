# feat(motion): lean animation path for scroll jank and reduced motion (spike 659)

## Summary

Adds a lean motion path behind `phase-164` (default off). Smooth scroll only runs where it's needed, the hero fades on a CSS scroll timeline, ScrollTriggers are batched, the H1 renders on the server and flips with WAAPI, infinite loops animate only `transform`/`opacity`, `will-change` lives only while something animates, and `prefers-reduced-motion` is honored by the ticker, skeletons, flap text and smooth scroll. It also fixes a gsap ticker leak on every route change (always on).

The flag is `phase-164` because upstream #573 assigned `phase-159` to the batched owner-key loader. Earlier lab runs set `NEXT_PUBLIC_FEATURE_PHASE_159`; that is now `NEXT_PUBLIC_FEATURE_PHASE_164`.

## Changes

- `app/layout.tsx`: stamps `data-phase-motion="lean"` when the build flag is set. Every CSS override is scoped to that attribute.
- `components/smooth-scroll.tsx`: Lenis only on `/` in lean mode, never under reduced motion; fixed teardown (the anonymous rAF callback was never removed).
- `components/hero-section.tsx`: CSS scroll-timeline fade with the gsap fallback.
- `colophon`, `principles`, `signals`, `work` sections, `highlight-text`: `ScrollTrigger.batch` reveals via `lib/motion-reveal.ts`, `quickTo` cursor, no scrub parallax in lean mode.
- `components/split-flap-text.tsx`: server-rendered final glyphs, `textContent` scramble, WAAPI settle flip, audio only when unmuted and motion is allowed.
- `app/tactical-command.css`, `app/globals.css`, `components/system-ticker.tsx`: compositor-only loops, `will-change: auto` unless interacting, reduced-motion freezes.
- `lib/motion-performance.ts`: pure helpers.
- `scripts/proof-motion-659.ts` (`npm run proof:659`): Lighthouse before/after runner.

## Files ruled out

`draw-text.tsx` and `scramble-text.tsx` have no importers. `app/explore/page.tsx` is covered by route scoping and the scoped CSS. `package.json` only gains the proof script.

## Flag and rollback

`NEXT_PUBLIC_FEATURE_PHASE_164`, build-time, default off. Rollback: unset, rebuild and redeploy. The scoped CSS goes inert and the legacy paths run. The ticker-leak fix stays on.

## Tests

- `lib/__tests__/motion-performance.test.ts` (12), including a CSS guard that every lean rule is attribute-scoped and compositor-only.
- `tsc --noEmit`: 0 errors. `vitest run`: green with flags off.
- Headless Chromium with the flag on: the server HTML has the final H1, the ticker's `will-change` is `auto`, and reduced motion turns off Lenis, the hero animation and the ticker. `/explore` runs without Lenis. No page errors.

## Live proof

Lab run on production builds (Lighthouse mobile, median of 5, two passes): on `/`, main-thread work is down 24–27% and Speed Index down 13–25%, with LCP and CLS flat. Reduced motion verified in headless Chromium: Lenis, the hero animation and the ticker all stop with the flag on, and the flag-off build keeps the legacy behavior.
