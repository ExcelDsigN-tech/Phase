# feat(docs): try-it-live API console on /docs (spike 662)

## Summary

Adds a "Try it live" console to `/docs` behind `phase-162` (default off). It has a typed request builder over the shared route contract, a response inspector that handles the API's awkward cases (JSON-RPC errors inside HTTP 200, the x402 shim's conditional 503, 429 with `Retry-After`), correlation-ID display, client-only wallet signing for signals, and a testnet fence for state-changing calls. Input is never lost on an error.

**Built on #526** (`feat/api-versioning-deprecation`): it uses that branch's `lib/api-contract.ts` as the route manifest and shows the `X-API-Version` echo. Merge #526 first.

## Changes

- `lib/api-playground.ts`: request builder, testnet fence and response classifier (pure, unit-tested).
- `components/docs-api-playground.tsx`: the console UI.
- `app/docs/page.tsx`, `lib/project-docs-content.ts`: a `playground` section when `NEXT_PUBLIC_FEATURE_PHASE_162` is set.
- `lib/phase-copy.ts`: `playground` strings, EN and ES.
- `lib/api-contract.ts`: `market` and `nft-listings` writes verify no signature, so they're `signing: "none"`.
- `scripts/proof-playground-662.cts` (`npm run proof:662`): live proof runner using the same lib code.

## Flag and rollback

`NEXT_PUBLIC_FEATURE_PHASE_162`, build-time, default off. Rollback: unset, rebuild and redeploy. The section disappears and nothing is persisted.
